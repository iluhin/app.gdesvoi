# ГдеСвои

**Чат вашего города.** Пишите тем, кто живёт рядом: новости района, советы,
«где купить», «кто видел» и просто разговоры — в общем чате города или лично.

## Как это устроено

Выбираете город — попадаете в его чат. Сейчас открыт двадцать один город, от
Мурманска до Краснодара и от Санкт-Петербурга до Красноярска; список ведёт
администратор. Город можно определить по геопозиции одним нажатием.

| | |
|---|---|
| 💬 | общий чат города и личные сообщения |
| 📎 | фото, видео и PDF прямо в сообщении |
| 👥 | кто сейчас онлайн, а кто отошёл |
| 🔔 | упоминания `@имя` подсвечиваются, у личных сообщений есть звук |
| 🙂 | профили с фото, «о себе» и ссылками на соцсети |
| 🤖 | ИИ-собеседник: обратитесь к нему по имени — и он ответит |
| 🌗 | светлая и тёмная тема |

Регистрация — имя, почта и пароль; почту подтверждает код из письма. Если
администратор включил гостевой вход, заглянуть можно и без регистрации.

## Приложение для Android

- **Отдельное окно.** Чат открывается с иконки, без адресной строки и вкладок
  браузера; ссылки на сторонние сайты уходят в обычный браузер.
- **Всё, что на сайте.** Вложения и фото из галереи, определение города,
  профиль — тот же аккаунт, что и на сайте.
- **Обновляется само.** О новой версии приложение узнаёт с сайта: показывает
  номер, размер и что изменилось; файл сверяется по контрольной сумме.
- **Лёгкое.** Меньше 100 КБ, никакой рекламы и трекеров.
- **Нужен** Android 7.0 или новее.

Файл берите [со страницы релизов](../../releases) или прямо
[с сайта](https://gdesvoi.ru/update.php?a=download) — все версии подписаны
одним ключом, поэтому обновление встаёт поверх.

## iPhone и компьютер

Отдельного приложения для iPhone нет, но сайт — это PWA: «Поделиться» →
«На экран „Домой“» даёт иконку и запуск без адресной строки. В Chrome на
Android и на компьютере — меню «⋮» → «Установить приложение» или пункт
«Установить приложение» в меню профиля в чате.

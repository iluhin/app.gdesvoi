# Роли и модерация

## Роли

| Роль | Кто это |
|---|---|
| **Чужой** | гость без регистрации; обычно может только читать и видеть, кто онлайн |
| **Гость** | роль по умолчанию для нового участника |
| **Житель** | полноправный участник: пишет, прикрепляет файлы, пишет в личку, ставит лайки |
| **Модератор** | следит за порядком: удаляет сообщения, замораживает и блокирует нарушителей |
| **Администратор** | всё перечисленное плюс настройки чата |

Что именно может каждая роль, решает администратор: в админке есть матрица
прав — галочки по ролям для каждого действия (писать в общий чат,
прикреплять файлы, личные сообщения, править и удалять свои сообщения,
загружать фото, ставить лайки, выбирать город, видеть онлайн, удалять чужие
сообщения, блокировать, назначать роли, входить в админку, менять
настройки, править матрицу прав).

## Меры модерации

Доступны из меню «⋮» у имени в списке онлайн и из таблицы пользователей в
админке.

| Мера | Что происходит |
|---|---|
| **Выкинуть** | пользователя выбрасывает из чата, он может войти снова |
| **Заморозить** на N минут | читает, но не пишет: поле ввода блокируется, приходит уведомление |
| **Заблокировать** на N минут | выход из чата и запрет входа до конца срока; срок виден при попытке войти |
| **Удалить сообщение** | сообщение исчезает у всех |

Ноль минут снимает заморозку или блокировку досрочно. Администратора нельзя
выкинуть, заморозить или заблокировать; изменить его роль может только
другой администратор.

## Правила

Пользовательское соглашение и политика конфиденциальности открываются по
ссылкам на экране входа и в уведомлении о cookie. Удалить аккаунт и все
данные можно по запросу с почты, указанной при регистрации, — адрес для
запросов указан в политике конфиденциальности.

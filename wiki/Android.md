# Приложение для Android

## Установка

1. Откройте <https://gdesvoi.ru/> с телефона.
2. На экране входа — ссылка **«Приложение для Android»** с номером версии;
   в чате тот же пункт есть в меню с вашим именем.
3. Android спросит разрешение на установку из этого источника — обычный
   вопрос для файла не из магазина. Разрешите один раз.
4. Готово: иконка на домашнем экране, чат открывается без адресной строки.

Прямая ссылка на свежий файл: `https://gdesvoi.ru/update.php?a=download`.
Он же лежит на [странице релизов](../releases).

**Что нужно:** Android 7.0 или новее. Приложение меньше 100 КБ.

**Какие разрешения и зачем:**

| Разрешение | Зачем |
|---|---|
| Интернет | чат работает в реальном времени |
| Приблизительная геопозиция | только по кнопке «Определить город»; без неё город выбирается из списка |

С версии 2.0 приложение не просит разрешение на установку других приложений.

Ни камеры, ни контактов, ни микрофона. Фото для вложений и аватара
выбираются через системное окно выбора файлов.

## Обновления

**Из магазина (RuStore)** — обновления ставит сам магазин, как у любого
приложения.

**С сайта** — когда выходит новая версия, чат внутри приложения показывает
окно с её номером и кнопкой «Скачать». Файл скачивается браузером, а
поставить его поверх нужно системным установщиком — вход, переписка и
настройки останутся на месте. Можно нажать «Позже», и до следующей версии
окно не появится.

Версия 1.0 обновлялась сама, скачивая файл с сайта. В 2.0 от этого
отказались: так требует RuStore, а установку ведёт магазин или система.

**Про подпись.** Все версии подписаны одним ключом, поэтому обновление
встаёт поверх. APK, скачанный откуда-то ещё и подписанный иначе, Android
поверх не поставит — берите файл только с сайта или со страницы релизов.

## Чем приложение удобнее вкладки

- Отдельная иконка и окно: чат не теряется среди вкладок браузера.
- Фирменная заставка, пока чат загружается в фоне: без белой вспышки и
  пустой страницы.
- «Назад» закрывает окна, меню и фото, возвращает в предыдущий раздел, а из
  чата сворачивает приложение.
- Строка состояния и панель навигации окрашены под шапку чата и следуют
  теме — светлой или тёмной.
- Ссылки на gdesvoi.ru открываются прямо в приложении, остальные — в
  браузере.
- Без сети — свой экран «Нет соединения»; когда сеть вернётся, чат откроется
  сам.

Аккаунт тот же, что на сайте: войти можно и там, и там.

## Если приложения не хочется

Сайт — это PWA: его можно добавить на домашний экран, и он будет
открываться без адресной строки, а без сети покажет страницу «Нет
соединения».

- **Android, Chrome:** меню «⋮» → «Установить приложение» (или пункт
  «Установить приложение» в меню профиля в чате).
- **iPhone, Safari:** «Поделиться» → «На экран „Домой“».
- **Компьютер, Chrome/Edge/Яндекс Браузер:** значок установки в адресной
  строке.

Отдельного приложения для iPhone нет: его можно собрать и подписать только с
платным сертификатом Apple. PWA на iPhone даёт то же самое.

## Что-то пошло не так

**«Установка заблокирована».** Android просит разрешить установку из этого
источника: Настройки → Приложения → Специальный доступ → Установка
неизвестных приложений → браузер (или «ГдеСвои» для обновлений) → разрешить.

**«Приложение не установлено».** Чаще всего уже стоит версия с другой
подписью. Удалите её и поставьте заново — переписка хранится на сервере, не в
телефоне.

**Не определяется город.** Разрешите приложению доступ к геопозиции:
Настройки → Приложения → ГдеСвои → Разрешения → Местоположение.

**Обновление не предлагается.** Если приложение из RuStore, обновление придёт
через магазин. Если с сайта и вы нажали «Позже», окно появится уже со
следующей версией — скачайте файл с сайта сами.

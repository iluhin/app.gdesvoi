# Как это устроено

Для любопытных — коротко и без исходников.

## Сайт

PHP 8 и MySQL, без фреймворков и сборщиков: страницы собираются на сервере,
интерфейс чата — обычный JavaScript.

- **Сообщения в реальном времени.** Браузер раз в пару секунд спрашивает
  сервер «что нового после сообщения N» и получает новые, исправленные и
  удалённые сообщения вместе со списком онлайн. Свернули вкладку — сервер
  сразу узнаёт, что вы «отошли».
- **Города.** Список ведёт администратор. Город по геопозиции — это
  ближайший из открытых по расстоянию по поверхности Земли.
- **Почта.** Коды регистрации и сброса пароля, письма-рассылки — через
  почтовый сервер сайта; у рассылок есть шаблоны оформления.
- **Права.** Каждое действие проверяется на сервере по матрице прав роли;
  интерфейс только прячет то, что всё равно не сработает.
- **Вложения** проверяются по настоящему типу файла, а не по расширению;
  скрипты в папке загрузок не исполняются.

## PWA

Манифест с иконками (включая «маскируемые» для Android), service worker:
страницы — сначала из сети, без сети — сохранённая копия или страница «Нет
соединения»; стили, скрипты и иконки — из кэша с обновлением в фоне. Запросы
к чату, файлы пользователей и админка не кэшируются никогда.

## Приложение для Android

Небольшая нативная оболочка над сайтом — без Gradle и сторонних библиотек.

- WebView с прикреплением файлов, геолокацией по запросу и мостом, через
  который сайт сообщает цвет шапки, — приложение красит под него системные
  панели.
- Ссылки на gdesvoi.ru открываются внутри, остальные — в браузере.
- **Заставка:** нативная, нарисована в коде; убирается, когда сайт через мост
  сообщает, что первый экран готов. Через тот же мост работает «Назад».
- **Обновления:** `update.php?a=check` отдаёт номер последней версии, размер,
  SHA-256 и заметку; сервер читает версию прямо из выложенного APK. С 2.0
  приложение само ничего не устанавливает: установки из магазина обновляет
  магазин, а установкам с сайта новую версию предлагает чат.
- Подпись одним ключом от версии к версии — иначе Android не поставит
  обновление поверх.
